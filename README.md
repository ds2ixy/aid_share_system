# 전문대학 AID 컨소시엄 · 공유학점 운영 현황

🔗 게시 주소: **https://ds2ixy.github.io/aid_share_system/**

공유학점(25~26학년도) 수강·수료 현황, 마이크로디그리 해당자, 개발·완료보고서 자동 생성 대시보드입니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 게시되는 대시보드 (자동 생성 파일, 직접 고치지 않음) |
| `src/template.html` | 대시보드 화면 · 기능 소스 |
| `src/build_data.py` | 엑셀 → 표준 자료(학기·대학·이름·아이디·출석·과제·시험·수료여부·교과목) 변환 |
| `src/inject.py` | 자료를 화면에 넣음 (게시용은 이름·아이디 마스킹, 실명 미포함) |
| `docs/reference/` | 화면·색상·교과목 구분 참고 이미지 |

## 자료와 자동 반영

- 원본 엑셀은 이 저장소에 두지 않고, 비공개 저장소 `aid_share_system_data`에 둡니다.
- 비공개 저장소에 엑셀을 고쳐 올리면, GitHub Actions가 이 저장소의 `src/`로 대시보드를 다시 만들어 `index.html`을 자동으로 올립니다.
- 이 저장소에 올라온 `index.html`은 GitHub Pages가 1~2분 안에 게시 주소에 반영합니다.

## 개인정보 처리

- 휴대폰·이메일·비밀번호 열은 대시보드에 넣지 않습니다.
- 게시용은 보기 전용입니다. 이름·아이디는 마스킹(`김*정`, `gtec2024*****`)된 상태로만 들어가고 실명은 파일에 없습니다.
- 입력·내려받기·실명 보기·마스킹 켜기/끄기는 관리자 전용 내부용에서만 합니다.
